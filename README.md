# Wren MW54 · visor 3D y anatomía

By **Jorge Andres Fajardo Mora**. The Wren MW54 micro-turbine built from its plans and installed in a 1:7 model of a jet trainer: assembly and exploded view, retractable gear with doors, flight controls, fuel mixture, combustion camera, live materials heat map and a flight simulator.
